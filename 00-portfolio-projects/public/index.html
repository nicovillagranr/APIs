Portfolio Projects API

REST API que sirve los proyectos y el perfil del portfolio de Nico Villagrán. Datos estructurados, CORS abierto, listos para consumir desde cualquier frontend.

Node.js json-server Deploy · Vercel
GET /projects Ver respuesta →

Devuelve el array completo de proyectos del portfolio: nombre, descripción, stack, tipo, estado, imagen y link al repo. El primer elemento de stack es siempre el lenguaje del proyecto ("JavaScript" o "TypeScript"): el cliente lo separa del resto para mostrarlo en su propia fila.
