Products API

REST API con 50 productos de moda para hombres, mujeres y niños. Cada producto expone nombre, categoría, tipo, descripción, imagen y precio — lista para consumir y filtrar en cualquier proyecto e-commerce.

Devuelve el array completo de productos (50 items). Soporta filtros nativos de json-server: ?categoria=Hombres, ?tipo=Calzado, ?_sort=precio&_order=asc.
